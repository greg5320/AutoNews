# AutoNews

Autonews — это агрегатор новостей с автоматической краткой выжимкой от gemini.
Проект полностью запущен и работает по адресу: **https://autonews.greg5320.ru**

Целью работы была практика в создании полноценного веб-сервиса: проектирование базы данных, работа со скрытыми воркерами и асинхронностью на Go, контейнеризация через Docker и безопасная настройка Nginx.

## Что можно найти на сайте

- **Посмотреть умную ленту:** По умолчанию для каждого нового посетителя загружаются посты Павла Дурова и новости из Hacker News.
- **Управлять источниками:** В разделе «Настройки ленты» можно отписаться от дефолтных подписок и привязать свои (поддерживаются как стандартные RSS-ссылки, так и публичные Telegram-каналы, например, через `@username`).
- **Читать выжимку без «воды»:** ИИ-генерация краткого содержания срабатывает отложенно, только в момент, когда карточка новости появляется на экране при прокрутке. Это снижает нагрузку на сервер.
- **Удалять новости и подписки:** Если скрыть новость или удалить источник, это произойдет только в вашем браузере (на бэкенде настроено разделение сессий через куки), для других пользователей лента останется нетронутой.

## Техническая часть

- **Бэкенд:** написан на Go. Используется фреймворк Gin для API и библиотека Sqlx для работы с базой данных. Внутри крутится асинхронный воркер-пул для параллельных ИИ-запросов к Gemini API и автоматический фоновый сборщик новостей.
- **Фронтенд:** написан на React/Next.js с использованием TypeScript и Tailwind CSS. Динамический интерфейс использует библиотеки framer-motion для плавной анимации и lucide-react для иконок.
- **База данных:** PostgreSQL. Хранит глобальную очередь постов, связи пользователей, подписки и таблицы индивидуально скрытых новостей.
- **Проксирование и безопасность:** Nginx выступает в роли единого прокси-сервера. База данных и бэкенд изолированы внутри сети Docker. Настроены безопасные SSL-сертификаты от Let's Encrypt и добавлено ограничение частоты запросов для защиты от спама.
- **Мониторинг:** К системе подключены Prometheus и Grafana для отслеживания загрузки процессора, оперативной памяти и количества запущенных горутин на сервере в реальном времени.
