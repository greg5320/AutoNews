# AutoNews

Это мой учебный пет-проект. Представляет собой простой агрегатор новостей из RSS-лент и публичных Telegram-каналов с автоматическим сумматором на базе искусственного интеллекта Gemini.

Проект создавался для практики работы с микросервисной архитектурой, Docker и асинхронной обработкой данных на Go.

## Возможности

- Автоматический сбор постов из Telegram-каналов (через публичный веб-интерфейс) и RSS-лент.
- Персонализация: каждый пользователь получает изолированный список подписок, скрытие удаленных новостей работает индивидуально через куки.
- Оптимизация затрат: ИИ-выжимка и теги генерируются только тогда, когда пользователь докручивает ленту до конкретной новости (lazy loading). Одинаковые новости для разных пользователей обрабатываются ИИ один раз.
- Безопасность: все сервисы и база данных скрыты во внутренней сети Docker, наружу смотрит только защищенный Nginx прокси с лимитами запросов.

## Стек технологий

- Бэкенд: Go (Gin, Sqlx)
- Фронтенд: Next.js (React, Tailwind CSS, TypeScript)
- База данных: PostgreSQL
- Прокси/SSL: Nginx
- Мониторинг: Prometheus, Grafana

## Как запустить локально

1. Создайте в корневой директории файл `.env` и укажите там ваш API-ключ:
   ```env
   GEMINI_API_KEY="ваш_ключ_от_gemini"
   ```

2. Запустите сборку и старт всех контейнеров:
   ```bash
   docker-compose up -d --build
   ```

Приложение будет доступно по адресу: `https://localhost` (Nginx автоматически создаст самоподписанный SSL-сертификат для локального тестирования).
