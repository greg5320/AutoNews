# AutoNews 📰

AutoNews — это небольшой pet-project (агрегатор статей с AI-анализом). 
Сервис принимает тексты, кладет их в очередь, а воркеры в фоне гоняют эти тексты через LLM (Gemini) для получения краткой выжимки, после чего сохраняют результат в PostgreSQL.

## Стек технологий
- **Golang** (Goroutines, Channels, Worker Pool)
- **PostgreSQL** (через `sqlx`)
- **REST API** (`gin`)
- **Docker & Docker Compose**

## Как запустить

Тебе понадобится ключ от Google Gemini API. Его можно бесплатно получить в Google AI Studio.

1. Экспортируй ключ в переменные окружения:
   ```bash
   export GEMINI_API_KEY="твой_ключ_здесь"
   ```

2. Подними базу и само приложение через Docker:
   ```bash
   docker-compose up -d --build
   ```

*(P.S. При первом запуске таблицы в БД нужно будет накатить руками из папки `migrations/`, авто-накатывание миграций пока не прикрутил. TODO: добавить golang-migrate)*

## API Эндпоинты

### Отправить статью на обработку
```bash
curl -X POST http://localhost:8080/articles \
  -H "Content-Type: application/json" \
  -d '{"title": "Тестовая новость", "content": "Здесь очень длинный текст, который нужно сжать."}'
```
Возвращает ID сохраненной статьи.

### Получить статью (включая AI-summary)
```bash
curl http://localhost:8080/articles/1
```
